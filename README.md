# Abstract
All-in-one image restoration, where a single unified model addresses multiple degradation types simultaneously, remains one of the most challenging open prob- lems in low-level computer vision. Existing methods either specialize in a single degradation (e.g., deblurring, deraining, dehazing) and suffer catastrophic failure on unseen types, or attempt multi-task learning but lack the representational flex- ibility to handle qualitatively different corruptions in a shared parameter space. We present KASIRNet, which introduces four tightly integrated technical contri- butions to address these shortcomings. First, the Spectral Resonance Block (SRB) performs amplitude modulation in the Fourier domain via a learned squeeze- and-excitation resonance gate, enabling degradation-adaptive frequency recovery. Second, the Semantic Injection Module (SIM) extracts frozen VGG19 features at four scales and fuses them into the restoration backbone through parallel channel and spatial attention, providing degradation-invariant structural priors. Third, the Shifted Cyclic Window Attention with Meshgrid (SCWAM) aug- ments shifted-window self-attention with explicit 2-D coordinate embeddings for geometric-aware global context. Fourth, a Prompt Learner encodes degradation type into a compact embedding that conditions every decoder stage via Spa- tial Feature Transform (SFT) affine modulation. These components are unified within our four-scale U-Net encoder–decoder trained end-to-end with a six-term Omni-Restoration Loss comprising pixel, FFT, perceptual, SSIM, identity, and edge objectives. Ultimately, trained across a broader collection of degradation- prompt categories, KASIRNet demonstrates competitive performance against the latest algorithms on eight standard benchmark degradation datasets without the need for task-specific labels at inference time, showcasing advantages in compu- tational efficiency as well as in both objective and subjective quality evaluations. Our code is available at (https://github.com/voxtranslate/KASIRNet)
